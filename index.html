02. Projects

UltronAI: General-Purpose AGI System

Modular multi-agent AGI system with 9 specialized agents for task decomposition, code generation, web research, error recovery, and document processing. State-driven architecture with intelligent planning and iterative quality refinement.

Multi-Agent•DeepSeek R1•Groq•Python

DiffuKnee: Diffusion-based MRI Segmentation

Diffusion-model + U-Net pipeline for automated multi-class knee MRI segmentation. Supports 2D and 3D inference, built-in dataset utilities, checkpointing with Dice/F1 and IoU metrics, and multi-GPU training via HuggingFace Accelerate.

PyTorch•Diffusion Models•U-Net•Medical Imaging

ClinSynapse: Multi-Agent Biomedical Assistant

Intelligent multi-agent biomedical research framework using LangGraph for dynamic workflow orchestration. Decomposes complex medical queries across specialized agents (MedILlama, Web Search, Reflection) with iterative self-improvement and parallel execution.

LangGraph•Multi-Agent•LLMs•Biomedical AI

ShapeRAGen: Text-to-STL Generation

End-to-end system converting natural language descriptions into validated, 3D-printable STL models using RAG. Integrates FAISS context retrieval and DeepSeek-V3 for high-fidelity geometry synthesis with hollow shape handling and automated printability checks (manifold/watertight validation).

RAG•FAISS•DeepSeek-V3•Trimesh•NumPy-STL
